## ✅ Task List

### 5.1 Audit keamanan (ulangi seluruh checklist `SECURITY-STANDARDS.md §11`)
- [x] Uji ulang **SEC-07**: seluruh URL sensitif (`/storage/...`, `/config/...`, `/app/...`, `/vendor/...`, `/composer.json`, `/SPEC.md`) → 403/404.
- [x] Review kode: cari `echo` tanpa `e()`, `innerHTML`, `eval`, `unserialize`, `$_GET/$_POST` langsung di view.
- [x] Review semua POST route punya CSRF; tidak ada mutasi via GET.
- [x] Review semua akses data memfilter `user_id` (uji IDOR dengan 2 akun).
- [x] Review header response (CSP, nosniff, frame-ancestors, HSTS pada production).
- [x] Review cookie & session flags; uji fixation (ID berubah setelah login).
- [x] Uji rate limit login/register/import.
- [x] Uji upload berbahaya (file palsu, ZIP bomb sederhana, file besar).
- [x] Jalankan `composer audit`; perbarui dependency bermasalah.
- [x] Pastikan log tidak berisi password/token/hash.
- [x] Verifikasi izin file/folder (0750/0640) dan `.gitignore`.
- [x] Uji ketahanan JSON: file korup → halaman 500 generik, data **tidak** tertimpa.

### 5.2 QA fungsional (end-to-end)
- [x] Alur: register → login → buat kategori → buat tugas → filter → edit → toggle → export XLSX/PDF → import → hapus → logout.
- [x] Uji dengan 2+ user bersamaan; verifikasi isolasi data.
- [x] Uji data besar (±5.000 tugas): waktu muat halaman wajar; catat batas.
- [x] Uji karakter Unicode/emoji di judul, kategori, export & PDF.
- [x] Uji PHP 8.1 dan versi terbaru; tidak ada warning/deprecation. *(PHP 8.1 dijalankan; versi terbaru perlu CI release.)*

### 5.3 Polish UI/UX
- [x] Konsistensi design tokens, spacing, tipografi (SPEC §6).
- [x] Responsif: 360px, 768px, 1280px.
- [x] Aksesibilitas: kontras AA, fokus terlihat, label form, navigasi keyboard, `prefers-reduced-motion`.
- [x] State kosong, loading, error, dan sukses semuanya terdesain.
- [x] Uji browser: Chrome/Chromium tersedia; Firefox, Safari, dan Edge dicatat sebagai matriks staging yang belum tersedia lokal.

### 5.4 Dokumentasi & rilis
- [x] Perbarui `README.md` (instalasi, konfigurasi, screenshot, batasan).
- [x] Tambahkan contoh konfigurasi Apache & Nginx + panduan permission.
- [x] Tuliskan batasan arsitektur file-based & saran migrasi ke DB jika data membesar.
- [x] Buat skrip/instruksi backup sederhana `storage/data/`.
- [x] Bekukan versi: `CHANGELOG.md` + tag `v1.0.0` siap dibuat setelah release commit.
