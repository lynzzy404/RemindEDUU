## 🎯 Tujuan
Menyiapkan kerangka proyek yang aman dan siap dipakai: struktur folder, autoload, bootstrap, router, JsonStore, helper view, dan design system neu brutalism dasar.

## 📦 Deliverables
- Struktur folder sesuai `SPEC.md §2.3`
- `composer.json` + dependency terinstal
- `app/bootstrap.php`, `Core/Router`, `Request`, `Response`, `View`, `Session`, `JsonStore`
- File JSON awal + proteksi akses
- `public/assets/css/app.css` (tokens + komponen dasar)
- Halaman "Hello RemindEDU" dan halaman error 404/403/500

## ✅ Task List

### 0.1 Inisialisasi proyek
- [x] Buat seluruh folder sesuai SPEC §2.3 (termasuk `storage/{data,logs,ratelimit,tmp}`).
- [x] `composer init`; set autoload PSR-4 `"App\\": "app/"`.
- [x] `composer require phpoffice/phpspreadsheet dompdf/dompdf`. Commit `composer.lock`.
- [x] Buat `.gitignore` sesuai **SEC-06**.
- [x] Pastikan ekstensi PHP terpenuhi (`mbstring json zip xml gd fileinfo`).

### 0.2 Proteksi storage (SEC-01/02/04)
- [x] Buat `storage/.htaccess` dan `storage/data/.htaccess` berisi `Require all denied`.
- [x] Buat `storage/data/index.html` kosong.
- [x] Inisialisasi `users.json`, `categories.json`, `tasks.json` dengan envelope `{"schema_version":1,"items":[]}`.
- [x] Atur izin folder 0750 / file 0640.
- [x] Buat `public/.htaccess` sesuai **SEC-81** dan contoh config Nginx di dokumentasi.

### 0.3 Bootstrap (`app/bootstrap.php`)
- [x] `declare(strict_types=1)`, set timezone, load config.
- [x] Error handling: `display_errors` hanya di `development`; production → log ke `storage/logs/app.log` (**SEC-70**).
- [x] Kirim security headers + CSP ketat (**SEC-41**); `header_remove('X-Powered-By')`.
- [x] Session hardening (**SEC-14**) lewat `Core/Session`.
- [x] Global exception handler → render `errors/500`.

### 0.4 Core
- [x] `Router`: dukung `GET/POST`, parameter `{id}` dengan validasi regex ID (`^(usr|cat|tsk)_[a-f0-9]{16}$`), 404 default.
- [x] `Request`: akses terkontrol ke input (`input()`, `string()`, `int()`), method, IP.
- [x] `Response`: `redirect()`, `notFound()`, `forbidden()`, helper download.
- [x] `View`: render dengan layout, helper `e()` (**SEC-40**).
- [x] `JsonStore`: `read()`, `transaction(callable)` dengan `flock` + atomic write + `JSON_THROW_ON_ERROR` (**SEC-05**, SPEC §3.6). Generator ID `prefix_ + bin2hex(random_bytes(8))`.
- [x] Router tidak boleh memetakan path ke file secara dinamis (**SEC-03**).

### 0.5 Design system dasar
- [x] `app.css`: design tokens dari SPEC §6.2, reset, tipografi.
- [x] Komponen: `.btn`, `.card`, `.input`, `.badge`, `.flash`, `.navbar`, grid responsif.
- [x] State hover/active/focus sesuai SPEC §6.3.
- [x] Layout `main.php` + partial navbar & flash (tanpa inline script/style).
- [x] Halaman error 404/403/500 bergaya brutalism.

### 0.6 Jalankan lokal
- [x] `php -S localhost:8000 -t public public/index.php` menampilkan halaman awal.
