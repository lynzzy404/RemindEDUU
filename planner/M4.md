## 🎯 Tujuan
User dapat mengekspor tugas ke **XLSX** dan **PDF**, serta mengimpor tugas dari file **XLS/XLSX** dengan validasi ketat dan laporan hasil per baris.

## 📦 Deliverables
- `ExportXlsxService`, `ExportPdfService`, `ImportService`
- `ExportController`, `ImportController`
- View `import/index`, template PDF `export/pdf`
- Template import `.xlsx` yang bisa diunduh

## ✅ Task List

### 4.1 Export XLSX (`GET /export/xlsx`)
- [ ] Ambil tugas milik user yang login, **mengikuti filter aktif** (reuse logika filter M3, tanpa pagination).
- [ ] Kolom: `Judul | Deskripsi | Kategori | Prioritas | Status | Tenggat` (identik dengan format import → round-trip). Tambahan opsional: `Dibuat`, `Selesai`.
- [ ] Label manusiawi (Rendah/Sedang/Tinggi, Belum/Proses/Selesai), tanggal `YYYY-MM-DD`.
- [ ] Header bold + warna kuning, auto-width, freeze header row.
- [ ] Anti formula injection: `setCellValueExplicit(..., TYPE_STRING)` + prefix `'` untuk awalan `= + - @ \t \r` (**SEC-62**).
- [ ] Nama file dibuat server `RemindEDU-YYYYMMDD-HHMM.xlsx` (**SEC-64**); header `Content-Disposition: attachment`, `nosniff`.

### 4.2 Export PDF (`GET /export/pdf`)
- [ ] Template HTML `export/pdf.php`: judul "RemindEDU", nama user, tanggal cetak, ringkasan, tabel tugas, gaya brutalism sederhana (border hitam, header kuning).
- [ ] Dompdf: `isRemoteEnabled=false`, `isPhpEnabled=false`, `chroot` terbatas, ukuran A4 landscape (**SEC-63**).
- [ ] **Semua** data di template di-escape dengan `e()`.
- [ ] Font bawaan Dompdf/DejaVu agar karakter Unicode aman; tidak memuat aset eksternal.
- [ ] Header `Content-Type: application/pdf`, attachment, nama file server-side.
- [ ] Tangani dataset besar: batasi (mis. 1000 baris) dan beri pesan jika terpotong.

### 4.3 Template Import (`GET /import/template`)
- [ ] Hasilkan `.xlsx` berisi header + 2 baris contoh + sheet "Petunjuk" (nilai yang diizinkan).

### 4.4 Import (`GET/POST /import`)
- [ ] Form upload (`enctype=multipart/form-data`) + CSRF + petunjuk format & batas.
- [ ] Rate limit endpoint import (**SEC-13**).
- [ ] Validasi upload sesuai **SEC-60**: `UPLOAD_ERR_OK`, `is_uploaded_file`, ukuran ≤ 2 MB, ekstensi `xls|xlsx`, MIME via `finfo_file`.
- [ ] Simpan sementara dengan nama acak di `storage/tmp/`; **hapus** di `finally`.
- [ ] Parsing: `IOFactory`, `setReadDataOnly(true)`; hanya sheet pertama; tolak jika baris > 1000 atau kolom berlebih (**SEC-61**).
- [ ] Verifikasi header baris 1 sesuai format; jika tidak → error jelas.
- [ ] Validasi tiap baris dengan aturan yang sama seperti form tugas (title wajib ≤ 120, deskripsi ≤ 1000, prioritas/status dipetakan dari label, tenggat valid). Nilai sel di-cast ke string, di-trim, control char dibuang.
- [ ] Tangani tanggal serial Excel → `YYYY-MM-DD` (`Date::excelToDateTimeObject`).
- [ ] Kategori: cocokkan nama (case-insensitive); jika belum ada → buat otomatis (maks 20 baru per import, warna dari palet bergilir).
- [ ] Simpan semua baris valid dalam **satu** `JsonStore::transaction`; backup `tasks.json` sebelumnya (SPEC §3.6.5).
- [ ] Hasil: ringkasan *diimpor / dilewati / kategori baru* + tabel error per baris (nomor baris + alasan, di-escape).
- [ ] `user_id` selalu dari session; kolom lain tidak boleh mengubahnya.
- [ ] Catat ke security log: upload ditolak & import sukses (jumlah baris) (**SEC-71**).

### 4.5 UI
- [ ] Tombol Export XLSX/PDF di halaman `/tasks` (menyertakan query filter aktif) dan halaman Import.
- [ ] Panel hasil import: kartu hijau (sukses) / merah (error).
- [ ] Indikator loading sederhana (JS eksternal) saat upload.

## 🧪 Skenario Uji
| # | Skenario | Hasil yang diharapkan |
|---|---|---|
| 1 | Export XLSX tanpa filter | File terbuka di Excel/LibreOffice, data sama dengan aplikasi |
| 2 | Export dengan filter status=done | Hanya tugas selesai |
| 3 | Judul tugas `=HYPERLINK("http://x","klik")` | Di Excel tampil sebagai teks, **tidak** menjadi formula |
| 4 | Export PDF | PDF rapi, karakter Indonesia benar, data ter-escape |
| 5 | Judul `<b>x</b><script>` di PDF | Tampil sebagai teks literal |
| 6 | Export user A vs B | Tiap user hanya memuat data sendiri |
| 7 | Import template yang diisi valid | Semua baris masuk, kategori baru terbentuk |
| 8 | Import hasil export (round-trip) | Berhasil tanpa error |
| 9 | Upload `.php` / `.exe` / file di-rename `.xlsx` | Ditolak (ekstensi/MIME) |
| 10 | File > 2 MB atau > 1000 baris | Ditolak dengan pesan jelas |
| 11 | Header kolom salah | Ditolak, pesan format |
| 12 | Campuran baris valid & invalid | Valid masuk, invalid dilaporkan per nomor baris |
| 13 | Sel berisi formula `=1+1` | Dibaca sebagai nilai/teks, tidak dieksekusi |
| 14 | Kategori baru > 20 | Dibatasi / ditolak sesuai aturan |
| 15 | File di `storage/tmp/` setelah import (sukses & gagal) | Sudah terhapus |
| 16 | POST import tanpa CSRF | 403 |
