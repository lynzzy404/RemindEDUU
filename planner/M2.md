## 🎯 Tujuan
User dapat mengelola kategori pribadi (CRUD) dan tersedia komponen **custom dropdown** yang aksesibel dan reusable untuk dipakai di form tugas serta filter.

## 📦 Deliverables
- `CategoryRepository`, `CategoryController`
- View `categories/index` + partial `partials/category_dropdown`
- `public/assets/js/dropdown.js` + styling dropdown di `app.css`

## ✅ Task List

### 2.1 Repository & logika
- [x] `CategoryRepository`: `allByUser()`, `findOwned($id, $userId)`, `create()`, `update()`, `delete()`.
- [x] Nama unik per user (case-insensitive), dicek **di dalam transaksi** JsonStore.
- [x] Warna divalidasi terhadap whitelist palet (SPEC §6.2).
- [x] Hapus kategori: set `category_id = null` pada semua tugas milik user yang memakai kategori tsb. **dalam satu transaksi** (tanpa cascade delete).
- [x] Batas wajar jumlah kategori per user (mis. 50).

### 2.2 Halaman kelola kategori (`/categories`)
- [x] Daftar kategori berupa kartu/chip berwarna + jumlah tugas per kategori.
- [x] Form tambah (nama + pemilih warna dari palet).
- [x] Edit inline/modal, hapus dengan modal konfirmasi (form POST + CSRF).
- [x] Semua route mutasi memakai POST + CSRF; cek kepemilikan → 404 jika bukan milik user (**SEC-20**).

### 2.3 Custom Dropdown (`dropdown.js` + partial)
- [x] Struktur: `button[aria-haspopup=listbox]` + `ul[role=listbox]` + `input[type=hidden]`.
- [x] Opsi menampilkan chip warna + nama; opsi pertama "Tanpa Kategori" (`value=""`).
- [x] Interaksi: klik buka/tutup, klik di luar menutup, **keyboard** (↑ ↓ Home End Enter Space Esc, type-ahead).
- [x] ARIA: `aria-expanded`, `aria-selected`, `aria-activedescendant`, label terhubung.
- [x] Data opsi dirender server-side di HTML (bukan inline script); JS hanya meningkatkan interaksi. Fallback `<select>` native dalam `<noscript>`.
- [x] Gunakan `textContent`, **bukan** `innerHTML`, untuk nama kategori (**SEC-40**).
- [x] Event listener dipasang dari file JS eksternal (patuh CSP, **SEC-41**).
- [x] Mendukung beberapa instance di satu halaman (form + filter) dan nilai awal (edit).
- [x] Styling neu brutalism: panel berborder 3px + hard shadow, hover kuning, opsi aktif tebal.

### 2.4 Integrasi
- [x] Siapkan helper view `category_dropdown($categories, $name, $selected)` untuk dipakai di M3.

## 🧪 Skenario Uji
| # | Skenario | Hasil yang diharapkan |
|---|---|---|
| 1 | Tambah kategori "Kuliah" warna kuning | Muncul di daftar & dropdown |
| 2 | Tambah nama duplikat ("kuliah") | Ditolak |
| 3 | Kirim warna di luar palet (edit via devtools) | Ditolak server |
| 4 | Edit/hapus kategori milik user lain (ubah ID di URL/form) | 404, tercatat di security log |
| 5 | Hapus kategori yang dipakai tugas | Tugas jadi "Tanpa Kategori", data tidak hilang |
| 6 | Nama kategori `<img src=x onerror=alert(1)>` | Tampil sebagai teks di daftar **dan** di dropdown |
| 7 | Navigasi dropdown hanya dengan keyboard | Bisa buka, pilih, tutup; fokus terlihat |
| 8 | JavaScript dimatikan | Fallback `<select>` tetap berfungsi |
| 9 | POST tanpa CSRF | 403 |
| 10 | Tampilan mobile | Dropdown tidak terpotong, target sentuh ≥ 44px |
